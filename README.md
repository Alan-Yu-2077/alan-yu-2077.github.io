# Alan Yu — résumé

<https://alanyu.here/>

A résumé you scroll through: a 3D tour of a desk, where each section lives in an object on it
(badge, monitor, keyboard, calendar, second screen, books, coffee, and a new badge at the end).
"Quick résumé" in the top bar opens a plain one-page version that prints to PDF.

This repository holds the built site only (Vite + three.js); GitHub Pages serves it from `main`.
Don't edit the files here by hand: they are replaced on every deploy.

The previous personal site (the one that opened with a film) is in this repository's history,
up to commit 321cfe3.
